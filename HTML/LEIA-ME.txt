# TripPlan — páginas iniciais

Esta pasta contém o primeiro modelo visual do site TripPlan.

## Arquivos
- `index.html`: página inicial
- `viagens.html`: cadastro e listagem de viagens
- `destinos.html`: cadastro e listagem de destinos
- `passeios.html`: cadastro e listagem de passeios
- `despesas.html`: cadastro e controle de despesas
- `css/style.css`: estilos compartilhados
- `js/script.js`: JavaScript inicial

## Como visualizar
Abra o arquivo `index.html` no navegador. Use o menu lateral para navegar entre as páginas.

Importante: por enquanto, as telas são apenas a estrutura visual. Os botões de salvar ainda não gravam dados. Vamos conectar os formulários ao Flask e ao SQLite nas próximas etapas.
