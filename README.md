
# TripPlan

Sistema de planejamento e organização pessoal de viagens.

## Sobre o projeto

O TripPlan é um sistema desenvolvido para ajudar pessoas a organizar suas viagens em um único lugar.

Com ele, é possível cadastrar viagens, organizar destinos, registrar passeios, controlar despesas e explorar sugestões de lugares para conhecer.

## Funcionalidades

- Cadastro e listagem de viagens.
- Cadastro e listagem de destinos.
- Cadastro e listagem de passeios.
- Cadastro e listagem de despesas.
- Sugestões de destinos.
- Filtros por categoria.
- Pesquisa de destinos.
- Sorteio de destino.
- Armazenamento de informações em banco de dados.

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Fetch API

## Organização do projeto

O sistema utiliza a arquitetura POO e DAO para organizar as classes e o acesso ao banco de dados.

## Como executar

1. Instale o Python.
2. Abra a pasta do projeto no VS Code.
3. Abra o terminal.
4. Instale as dependências:

   pip install -r requirements.txt

5. Execute o sistema:

   python app.py

6. Abra o navegador e acesse:

   http://127.0.0.1:5000

## Banco de dados

O banco SQLite é criado automaticamente na pasta database, utilizando o arquivo tripplan.db.
